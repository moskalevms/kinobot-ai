# admin-security Specification

## Purpose

Определяет правила создания учётной записи администратора и обработки
секретов админ-панели: обязательные значения из переменных окружения,
запрет учётных данных и секретных ключей по умолчанию, запрет вывода
паролей в консоль и логи.

## Requirements

### Requirement: Обязательный пароль администратора из окружения

При инициализации базы данных система ДОЛЖНА (MUST) создавать учётную
запись администратора только с паролем из переменной окружения. Если
переменная не задана, инициализация ДОЛЖНА (MUST) завершаться ошибкой.
Создание учётной записи с паролем по умолчанию ЗАПРЕЩЕНО (MUST NOT).

#### Scenario: Пароль не задан

- **WHEN** инициализация базы данных запускается без заданной переменной
  окружения с паролем администратора
- **THEN** процесс завершается с ошибкой и понятным сообщением, учётная
  запись администратора не создаётся

#### Scenario: Пароль задан

- **WHEN** инициализация базы данных запускается с заданным паролем
  администратора в окружении
- **THEN** создаётся учётная запись администратора, вход возможен только
  с этим паролем

### Requirement: Запрет вывода секретов

Система НЕ ДОЛЖНА (MUST NOT) выводить пароли, токены и иные секреты
в консоль, логи или страницы интерфейса — ни при инициализации,
ни при работе.

#### Scenario: Инициализация не раскрывает пароль

- **WHEN** учётная запись администратора создаётся при инициализации
- **THEN** в выводе процесса и в логах отсутствует значение пароля

### Requirement: Обязательный секретный ключ веб-сессий

Веб-приложение ДОЛЖНО (MUST) использовать секретный ключ сессий только
из переменной окружения. Запуск в производственном окружении без
заданного ключа ЗАПРЕЩЁН (MUST NOT); значение по умолчанию вместо ключа
ЗАПРЕЩЕНО (MUST NOT).

#### Scenario: Запуск продакшена без ключа

- **WHEN** веб-приложение запускается в производственном режиме без
  заданного секретного ключа сессий
- **THEN** приложение не запускается и сообщает причину

#### Scenario: Запуск в разработке без ключа

- **WHEN** веб-приложение запускается в режиме разработки без ключа
- **THEN** приложение запускается с временным ключом и предупреждением
  в логе

### Requirement: CSRF-защита форм админ-панели

Все формы админ-панели (вход, смена пароля, смена почтового адреса)
ДОЛЖНЫ (MUST) отправлять запрос с валидным CSRF-токеном.
POST-запрос формы без токена или с невалидным токеном ДОЛЖЕН (MUST)
быть отклонён до выполнения действия; состояние (вход, пароль, почта)
при этом изменяться НЕ ДОЛЖНО (MUST NOT).

#### Scenario: Отправка формы без токена

- **WHEN** из браузера отправляется POST-запрос любой формы
  админ-панели без валидного CSRF-токена
- **THEN** запрос отклоняется, вход не выполняется, пароль и почтовый
  адрес не изменяются

#### Scenario: Отправка формы с валидным токеном

- **WHEN** администратор заполняет форму входа, смены пароля или смены
  почты на странице админ-панели и отправляет её с корректным
  CSRF-токеном
- **THEN** действие выполняется как раньше (вход, смена пароля,
  смена почты), результат отображается пользователю

#### Scenario: Поддельная страница не может сменить пароль

- **WHEN** пользователь, вошедший в админ-панель, открывает стороннюю
  страницу, которая пытается отправить форму смены пароля от его имени
- **THEN** запрос отклоняется, пароль не изменяется

### Requirement: Безопасный запуск встроенного веб-сервера

Запуск веб-приложения встроенным сервером разработки
(`python src/app.py`) НЕ ДОЛЖЕН (MUST NOT) включать интерактивный
отладчик запросов и НЕ ДОЛЖЕН (MUST NOT) слушать внешние сетевые
интерфейсы: приложение ДОЛЖНО (MUST) быть доступно только через
локальный интерфейс (127.0.0.1). Для продакшена встроенный сервер
разработки не используется.

#### Scenario: Запуск веб-приложения локально

- **WHEN** разработчик запускает веб-приложение командой
  `python src/app.py`
- **THEN** приложение слушает только 127.0.0.1:5000, при ошибке
  в запросе интерактивный отладчик с выполнением кода не предоставляется

#### Scenario: Ошибка в запросе не раскрывает отладчик

- **WHEN** обработчик запроса встроенного сервера завершается
  необработанным исключением
- **THEN** клиент не получает страницу интерактивного отладчика,
  позволяющую выполнить произвольный код
