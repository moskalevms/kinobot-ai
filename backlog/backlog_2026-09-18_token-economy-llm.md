# Бэклог: экономия токенов LLM (opencode-конфигурация + kinobot-ai)

*Дата: 2026-09-18 | Источник: `docs/research/token-economy-llm-2026-09-18.md` | Приоритизация: ценность/стоимость — P0 (быстрые победы, нулевая/минимальная стоимость, максимальный эффект), P1 (умеренная работа с явной ценностью), P2 (опционально/отложено — требует инфраструктуры, трафика или внешних зависимостей).*

## Допущения (зафиксированы планировщиком)

1. Задачи A1–A5, B1–B3 меняют конфигурацию opencode (`~/.config/opencode/opencode.jsonc`, `.opencode/agent/*.md`, `AGENTS.md`) — для них «готово» = проверяемый критерий приёмки по конфигурации (не ruff/mypy/pytest). Задачи, трогающие код kinobot-ai (B4, B5, C1–C3, C5), верифицируются по AGENTS.md: `ruff check .` + `mypy` + `pytest` зелёные (интерпретатор `.venv`, `PYTHONIOENCODING=utf-8`).
2. Отчёт предупреждает (раздел Methodology): часть полей конфига opencode (`compaction.prune`, `small_model` и т.п.) в новых версиях могла переехать в v2-схему (`keep.tokens`/`buffer`). Исполнитель каждой config-задачи ОБЯЗАН сверить поле со схемой `https://opencode.ai/config.json` и отсутствием ошибок при запуске opencode.
3. Наличие `opencode stats --models --days N --tools N` подтверждено локально (флаги существуют в установленной версии).
4. Поддержка per-agent `effort`/`model` во frontmatter `.opencode/agent/*.md` окончательно не подтверждена — проверяется в A4/B3; при отсутствии поддержки задача закрывается документированным fallback (ручная процедура) с пометкой «частично».
5. GigaChat API (основной LLM kinobot-ai) документированной поддержки явного промпт-кэширования не имеет — проверка вынесена в C1; `cacheControl: true` относится только к каналу opencode ↔ Alibaba endpoint и kinobot-ai не затрагивает.
6. Все правки AGENTS.md и конфигов применяются МЕЖДУ сессиями (префиксный кэш Anthropic-совместимого endpoint: любое изменение начала префикса инвалидирует кэш, TTL 5 минут).
7. Новое исследование не проводилось; все цифры и ссылки — из отчёта-источника.
8. Секреты (API-ключи из `~/.config/opencode/opencode.jsonc`) в бэклог и отчёты не копируются.

## Риски и ограничения

1. **Версия схемы opencode**: поля `compaction.prune`, `limit.context`, per-agent options могли мигрировать в v2-схему (`keep.tokens`/`buffer`) — каждая config-задача начинается со сверки со схемой и заканчивается запуском без ошибок (отчёт, Methodology).
2. **Инвалидация префиксного кэша**: любые правки AGENTS.md/конфигов посреди активной серии запросов сбрасывают кэш (TTL 5 мин, перезапись 125%) — все задачи Epic A/B1 применять между сессиями (отчёт §2.8, §6).
3. **Качество vs экономия**: снижение effort (A1/A4) и дешёвая модель (B3) могут ухудшить результат на сложных задачах — митигация: per-agent матрица, baseline/контрольные замеры A5, откат из резервной копии.
4. **Промпты — источник поведения kinobot-ai** (ловушка AGENTS.md): задачи B4/B5 меняют поведение бота без правки кода логики — обязательны итеративность и прогон pytest после каждого шага; «готово» только при ruff+mypy+pytest зелёных.
5. **Ограничение token-plan endpoint**: подписочный план Alibaba может не давать доступа к другим моделям (блокирует B3) и не поддерживать batch/context editing (блокирует C3/C6) — задачи имеют явный выход «недоступно/отложено» с документированием.
6. **GigaChat без явного кэширования** (допущение 5): главный эффект отчёта (−90% на префиксе) для продакшен-канала kinobot-ai может быть недостижим до C1-проверки; не закладывать экономию в ожидания.
7. **Замер эффекта зависит от локальной истории** `opencode stats` — при её очистке baseline теряет смысл (A5).
8. **Конфиги вне репозитория**: `~/.config/opencode/opencode.jsonc` не версионируется git — изменения непрозрачны для команды; митигация: резервные копии + фиксация применённых значений в `docs/token-budget.md`. Секреты из конфига в репозиторий не копировать.
9. **Совокупный ожидаемый эффект** (отчёт, Key Takeaway 10): 50–85% сокращения токенов/затрат при выполнении P0+P1; цифры скидок сторонних обзорников местами экстраполированы — перепроверены отчётом по официальным докам, но фактический эффект подтверждать только замерами A5.
