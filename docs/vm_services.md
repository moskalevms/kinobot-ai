## Что сделать перед первым деплоем

1. Подготовить `.env.production` на VM; обязательно включить:
   - `FLASK_ENV=production`;
   - `FLASK_SECRET_KEY` — случайное значение (без него `app.py`
     не стартует, это проверка встроена в код);
   - `ADMIN_PASSWORD` — для создания админа через `init_db.py`
     (без него инициализация завершается ошибкой);
   - ключи интеграций: `TELEGRAM_BOT_TOKEN`, `KINOPOISK_API_KEY`,
     `GIGACHAT_AUTH_KEY`.
2. Определиться с составом сервисов: только бот или бот + веб/админка
   (текущий образ в `Dockerfile` запускает только бота; для веба
   нужен отдельный сервис/команда `python src/app.py` или gunicorn).
3. Выполнить `python init_db.py` после поднятия PostgreSQL.
4. После развёртывания обновить этот документ фактическим составом
   сервисов и датой подтверждения.
