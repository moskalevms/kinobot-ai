# Справка администратора: эндпоинты веб-приложения

Веб-приложение (Flask) запускается командой `python src\app.py` и по умолчанию
слушает порт 5000. Все административные роуты зарегистрированы с префиксом
`/admin` (`src/admin_routes.py`), проверка доступности и публичный
веб-интерфейс — в `src/app.py`.

## Проверка доступности

| Метод | Путь | Назначение | Авторизация |
|-------|------|------------|-------------|
| GET | `/health` | Health check: проверяет внешние зависимости (Kinopoisk API) и считает активные сессии | Не требуется |

Возможные ответы `GET /health`:

| Код | Тело ответа | Значение |
|-----|-------------|----------|
| 200 | `{"status": "healthy", "sessions_count": <N>}` | Сервис работает, внешние зависимости доступны |
| 503 | `{"status": "unhealthy"}` | Внешние зависимости недоступны |
| 500 | `{"status": "error"}` | Внутренняя ошибка при проверке |

Эндпоинт подходит для мониторинга на VPS.

## Админ-панель

Доступ к разделам (кроме `/admin/login`) требует входа пользователем с ролью
`admin` (`admin_required` в `src/admin_routes.py`). Вход — `/admin/login`.

| Метод | Путь | Назначение | Авторизация |
|-------|------|------------|-------------|
| GET, POST | `/admin/login` | Страница входа; вход только для пользователей с ролью `admin`, при успехе редирект на `/admin/dashboard` | Не требуется |
| GET | `/admin/logout` | Выход из системы, редирект на `/admin/login` | Требуется вход |
| GET | `/admin/dashboard` | Главная панель статистики: уникальные пользователи и запросы за сегодня, месяц и всё время, график за 30 дней | Роль `admin` |
| GET | `/admin/statistics` | Детальная статистика с графиками; период задаётся параметром `?days=<N>` (по умолчанию 30) | Роль `admin` |
| GET | `/admin/users` | Список пользователей системы | Роль `admin` |
| GET, POST | `/admin/profile` | Профиль администратора: смена пароля и почтового адреса | Роль `admin` |

## Публичные эндпоинты веб-интерфейса

| Метод | Путь | Назначение | Авторизация |
|-------|------|------------|-------------|
| GET | `/` | Главная страница веб-интерфейса (чат) | Не требуется |
| POST | `/chat` | Отправка сообщения в чат; тело — JSON `{"message": "<текст>"}`. Ответ — JSON с полями `response`, `needs_clarification` и, при наличии, `movie`/`parameters`. Освобождён от CSRF-токена | Не требуется (пользователь идентифицируется по сессии) |
| POST | `/new-chat` | Очистка истории диалога текущего пользователя; ответ — `{"status": "success", ...}`. Освобождён от CSRF-токена | Не требуется (по сессии) |
